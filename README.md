# ANU SOLS LTD Website

Premium business website for ANU SOLS LTD, built with React, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Design direction

- Palette: ink navy, trust blue, signal mint, cloud white.
- Typography: Sora for headings, Inter for body copy.
- Style: premium corporate, minimal, responsive, smooth animated sections.
- Conversion goals: project enquiries, consultations, newsletter subscriptions, and direct contact.
